# Pebble Intelligence for desktop

The company workspace you ask instead of scroll, as an app for **Windows, macOS and Linux**.

**Download:** https://pebble.pebblecart.com/download (or https://pebble-intelligence.vercel.app/download), which picks the right file for your computer. All files are also under [Releases](https://github.com/aviinashmishra/pebble-intelligence-desktop/releases/latest).

| Computer | File |
| --- | --- |
| Windows 10/11 | `Pebble-Intelligence-Setup-<version>.exe`: installs for you only (no admin rights) and updates itself. No install: the portable `.exe` or the `-win-x64.zip` |
| macOS 12+ (Apple silicon and Intel) | `Pebble-Intelligence-<version>-universal.dmg` |
| Linux x64 | `Pebble-Intelligence-<version>-x86_64.AppImage`: `chmod +x`, then run. Updates itself |

Open the app and sign in with your **@pebblecart.com** email. It connects to the company's live Pebble; nothing is set up on your computer.

**First run:** Windows may say "Windows protected your PC". Choose **More info → Run anyway**. On macOS, right-click Pebble → **Open** the first time.

This repository holds installers only. They're built and published automatically by the Pebble Intelligence project.
